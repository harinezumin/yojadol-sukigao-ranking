# ♡ ヨジャドル好き顔ランキング

女性K-POPアイドルの写真を2人ずつ見比べて、直感で好きな方を選ぶランキングサイトの試作版です。

## 使い方
1. `index.html` / `style.css` / `script.js` を同じフォルダに置く
2. `images` フォルダに画像を入れる
3. `script.js` の `IDOLS` にメンバーを追加する
4. `index.html` をブラウザで開いて動作確認する

## GitHub Pages
GitHubで新しいRepositoryを作成し、このフォルダの中身をアップロード。
Repository Settings → Pages → Deploy from a branch → `main` / `/(root)` を選択すると公開できます。

## 画像について
この試作版にはアイドル写真そのものは同梱していません。
公開する場合は、使用する写真の権利・利用条件を必ず確認してください。
